# Engineering Portfolio | rgelani.github.io

A high-performance, minimalist portfolio showcasing Full-Stack expertise in the Shopify ecosystem, AdTech, and IoT.

## 🚀 Overview

This portfolio is designed with a focus on **Visual Storytelling** and **Technical Depth**. It utilizes a vertical scroll-snapping architecture and a Bento-grid modal system to provide a premium user experience while maintaining high performance.

## 🛠️ Technical Stack

- **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, CSS Grid)
- **Interactions:** Vanilla JavaScript (ES6+)
- **Architecture:** - **Scroll Snapping:** Native CSS `scroll-snap` for smooth section transitions.
  - **Dynamic Modals:** Custom JS-driven modal system for technical case studies.
  - **Media:** Optimized HTML5 Video and Image carousels.

## 📁 Project Highlights

### 1. Trust Subscription Engine (Fintech)
* **Role:** Lead Developer
* **Challenge:** Transitioning Shopify stores to recurring revenue models.
* **Key Tech:** Laravel, Shopify Billing API, Redis Queues.

### 2. Metafields Configuration (Merchant Utility)
* **Challenge:** Managing complex, native Shopify data structures.
* **Key Tech:** GraphQL, Laravel Horizon, Node.js.

### 3. TikPix Tracking (AdTech)
* **Challenge:** Automating TikTok Pixel injection and conversion event tracking.
* **Key Tech:** TikTok API, Pixel Automation, Laravel Scheduler.

### 4. QLEM Smart Cards (IoT)
* **Challenge:** Bridging physical NFC hardware with cloud-based digital profiles.
* **Key Tech:** NFC Protocol, Dynamic Redirection Service.

## 🎨 Design Philosophy

The site follows **Apple’s Design Language**:
- **Typography:** Clean, San Francisco-style sans-serif hierarchy.
- **Bento Grids:** Feature-dense cards for high scannability.
- **Glassmorphism:** Subtle blur effects and clean borders (`backdrop-filter`).
- **Performance:** Zero external CSS/JS libraries (No Bootstrap/jQuery) for near-instant load times.
